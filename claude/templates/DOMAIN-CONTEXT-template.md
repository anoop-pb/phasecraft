# Domain context

Domain expertise every role that reads this file assumes, in addition to its own role. Written by the operator at onboarding, refined as the domain is better understood. Framed as "Assume expertise in …", never "You are …" — roles already have identities.

This file gives those roles a domain expert’s lens: how each stakeholder reasons, what they value and are wary of, the terms they use, and the hard constraints that should change a design decision. A role that has read it weighs choices as an experienced practitioner in the domain would, and still asks where its inputs are silent.
